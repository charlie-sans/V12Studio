## how to build

requirements: 
- vcsdk - with content synced
- dotnet 10

to build V12Studio, just run
`vcsdk build -r nova`, using the `-r` option to select the Nova Renderer.

in `./bin` you will find `V12Studio.exe` next to `V12Studio.v12pak`

you built the editor!
